## 🚀 Проекти

### GhostShield SDK
*Заобикаляне на Bot Detection за Тестване*
- Заобикаля Cloudflare, Akamai, PerimeterX за легитимно E2E тестване
- TLS fingerprint spoofing, симулация на човешко поведение
- npm пакет с React/Vue адаптери
- **Технологии:** TypeScript, Playwright, Puppeteer

### ChronoSync SDK  
*Time-Travel State Management*
- Undo/redo, история на snapshots, разклоняване на timeline
- Адаптери за React и Vue фреймуърки
- Пълна TypeScript поддръжка с JSDoc документация
- **Технологии:** TypeScript, React, Vue 3

### Aeterna Empire
*Enterprise QA SaaS Платформа*
- Multi-tenant система за управление на тестове
- AI-базирано генериране на тестове
- Real-time dashboard за изпълнение на тестове
- Worker-базирано паралелно изпълнение на тестове
- **Технологии:** Next.js, Hono, Prisma, PostgreSQL, Redis
